# CLINISIGNAL AI — Streamlit Demo

Interactive research prototype using an entirely synthetic ICU-style dataset. This is a technical demonstration only; it is not a medical device and must never guide patient care.

## Included
- Synthetic ICU dataset (`data/synthetic_icu.csv`)
- Patient-level train/validation/test split (192 / 48 / 60 patients)
- Logistic Regression baseline pipeline with training-only median imputation and scaling
- Threshold selected on validation data only
- Streamlit dashboard: manual/sample risk estimation, patient explorer, evaluation metrics, and limitations

## Run locally

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python src/train_model.py
streamlit run app.py
```

If the CSV is missing, regenerate it with `python src/generate_data.py` before training.

## Deploy
Push this folder to a GitHub repository and deploy `app.py` with Streamlit Community Cloud. Set the repository root as the app root and use `requirements.txt` for dependencies.

## Safety and interpretation
All observations and event labels are artificial and generated by programmed rules. The target `risk_event_within_6h` is a simulated event label, not a Sepsis-3 diagnosis. Metrics are software-demo metrics on this synthetic dataset only and are not real-world sepsis performance estimates. SHAP is not implemented in this version. Do not use for clinical decisions, diagnosis, or treatment.
